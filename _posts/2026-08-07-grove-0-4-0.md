Since the beginning, Grove's Agent pane has run exactly one coding agent per checkout — switching agents meant ending whichever session was already running, confirmation dialog and all. 0.4.0 breaks that assumption: you can now run more than one agent at once, each in its own tab. That's the headline, but there's a decent stack of smaller-but-real changes riding along with it — a proper address bar in Home, a git panel that stops dumping raw errors at you, and clickable terminal links.

## Run more than one agent at once

The Agent pane now works the way browser tabs do. Your existing setup — whichever agent you picked in Settings — is still there, unchanged, as the default tab. A new "+" button next to it opens a second, independently running agent, in its own tab, with its own name and its own choice of agent (Claude Code in one, opencode in another, whatever mix you want). Each tab keeps running while you're looking at a different one, and closing a tab only asks for confirmation if that agent is actually still active.

This was the one structural limit that kept surfacing whenever a checkout genuinely had two things going at once — say, one agent working through a refactor while you wanted a second one available for a quick, unrelated question, without ending the first session to get it.

## An address bar for Home

The Home tab's pinned sites used to show a static, uneditable URL in the toolbar. Now there's an actual address bar: type a URL and go there directly, hit a Home button to snap back to the site's pinned URL after following a link somewhere else on the page, or use a new "Pin This Page" button to save wherever you've navigated to as a new pinned site — without leaving Home to do it by hand. The Reload button also picked up a Cmd+R shortcut, since typing a URL and then reaching for the mouse to refresh it was its own small annoyance.

## Git sync gives you a way out

If `git pull` failed because your working tree was dirty, Grove used to show you git's raw stderr in an alert with a single "OK" button and a hint to check the Shell pane — which was actively wrong, since pull runs as a background process that never touches the interactive shell. That dialog is gone. A failed pull on a dirty tree now offers **Stash, Pull & Restore** directly, which does exactly what it says and never drops your stash if the restore step hits a conflict. A rejected push points you at the existing Sync button instead of printing git's own wording.

Alongside that, the sidebar now shows a small badge on any workspace with commits sitting local that were never pushed, and quitting Grove with unpushed work anywhere prompts you first — both places that badge would previously go unnoticed until you happened to open that workspace's git panel yourself.

## Links in the terminal are clickable

Cmd+clicking a hyperlink inside the Agent or Shell pane — a PR link an agent printed, a local dev server address — now actually does something. A new Settings option decides where it opens: in Grove's own Home tab, or your system browser. Previously this silently fell through to whatever the terminal library defaulted to, which wasn't configurable and wasn't even documented.

## Smaller things

- **Diff headers can show the full file path** instead of just the filename, with a Settings toggle if you'd rather keep the shorter version — useful the moment a repo has two same-named files in different folders.
- **Marking a file reviewed in the Diff tab now advances you to the next unreviewed file** automatically, instead of leaving the just-reviewed file selected.
- **A confusing "command failed" alert during fast workspace or worktree switching is fixed.** It was firing on completely routine navigation, not an actual git problem.
- **Scrolling in the Agent pane no longer confuses Claude Code's own interface.** Mouse-wheel input is now suppressed for Claude Code by default (other agents that use it, like opencode, are unaffected), fixing a case where a stray scroll could make Claude Code think a button was stuck down.
- **A narrow license-verification edge case that could incorrectly flag a valid license as invalid is fixed.** This only ever affected a specific edge case, not day-to-day license checks.

## Get it

Grove 0.4.0 is up now — [grove.molayab.com](https://grove.molayab.com) for a fresh download, or the in-app update check if you're already on 0.3.2.

Multiple agent tabs is the change I'd been putting off the longest, mostly because it touched the same plumbing the Shell pane's own multi-tab support already used — once that pattern existed in one place, extending it to Agent was more a matter of finally doing it than figuring out how.
