0.6.2 is a one-fix release, and the fix is for a bug that was hard to miss once you'd seen it: moving the pointer over the Agent or Shell pane could act like a click. If you were running an agent with a mouse-aware interface — Claude Code is the obvious one — sliding the mouse across the pane on your way somewhere else could select whatever option or button it passed over. It's fixed, and it seemed worth shipping on its own instead of waiting for the next feature release.

## What was going wrong

Terminal programs that use the mouse ask the terminal to report what the pointer is doing — clicks, releases, and, if they want it, plain movement. Grove's terminal panes were reporting movement wrong. When the pointer moved with no button held, the pane told the program "the left button was just released here" instead of "the pointer moved here, nothing pressed."

To a program that reads those reports, a release right after nothing is a finished click. So every bit of pointer movement over the pane registered as a click on whatever was underneath. A plain shell prompt doesn't ask for mouse reports, so it didn't notice, but anything with a clickable interface did, in either pane, and there was no setting to work around it.

Now Grove reports movement the same way Terminal.app and other common terminals do, so programs see a hover as a hover.

## Behind the scenes

The rest of 0.6.2 is release-pipeline work: builds are now made with a fixed toolchain instead of whatever happened to be newest, so the app you download is built the same way each time. You won't see any difference in the app.

## Get it

Grove 0.6.2 is up — [grove.molayab.com](https://grove.molayab.com) for a fresh download, or accept the update alert if you're already on 0.6.1.

Bugs like this are easy to misread because they look like the program's fault. When an agent's interface reacts to a cursor that's only passing through, the natural thing is to blame the agent, not the terminal hosting it. If something inside a Grove pane behaves differently than it does in your usual terminal, report it with **Help › Report a Bug…**. The terminal hosting the agent is part of what you're using, and it can be the thing that's wrong.
