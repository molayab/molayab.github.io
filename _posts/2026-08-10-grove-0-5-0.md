Three things changed meaningfully in 0.5.0: the sidebar got a visual redesign that adds live status at a glance, the terminal plumbing got a thorough audit that fixes a class of silent agent failures, and the git log picked up a contextual action for dropping an unpushed commit — without making you drop to the command line to do it.

## A new sidebar

The tab strip on the left is now a narrow icon rail instead of a full-width tab bar. Each space gets an icon with an accent-tinted highlight when selected, and a tooltip that shows the live title if you hover. The workspace entries themselves now show a colored initial badge — a circle with the first letter of the workspace name, color derived from the name — instead of the generic folder icon that made every workspace look identical at a glance.

The more useful change is that the icons now carry live badges. The Agent icon shows a dot when any of that space's processes has exited unexpectedly. The Files icon shows a count of changed files in the working tree, and that count updates automatically as you commit, switch branches, or check out — no manual refresh.

There's also a QuickLook crash fix in here. The Files space occasionally crashed on first open after switching to a checkout. That's fixed.

## Agents actually inherit your environment now

This one has been quietly causing problems since the beginning. When Grove launches an agent — Claude Code, opencode, Codex, or any of the others — it was starting with a minimal environment that missed a lot of what agents actually depend on: version-manager paths set up by nvm, volta, pyenv, or similar; SSH auth sockets that remote git operations go through; API keys set in your shell profile. An agent installed via Homebrew would fail to find its own dependencies. A key set in `.zshrc` wouldn't be there. The failure mode was usually silent — the agent would just report that something wasn't available, with no indication that the environment was the cause.

0.5.0 fixes this. Agent sessions now start from a login shell, which sources your profile and `.zshrc` before handing off to the agent — so everything your shell normally provides is there. Environment variables relevant to SSH and session identification are passed through explicitly on top of that. The agent binary is still what runs in the PTY; the shell step is just the setup before the handoff.

Shell sessions are untouched — they already handled this correctly and don't need the wrapper.

Separately, `TERM_PROGRAM` is now set to `grove`, which is how terminal-aware tools identify the host when deciding things like color depth support or whether to use hyperlinks. Some agents branch on this.

## A rendering fix for full-screen TUI apps

If you've ever opened a full-screen TUI inside the Agent or Shell pane — something like a menu-driven CLI tool or a status dashboard — and seen the previous terminal content bleed through instead of being fully replaced, that's fixed. The terminal was sometimes not fully repainting when a full-screen app activated its own drawing buffer, leaving stale rows visible until something forced a refresh. The fix ensures a full repaint happens on every buffer switch.

## Drop Commit

The recent-commits section in the git sidebar now has a context menu. Right-clicking a commit gives you **Copy Hash**, **Copy Short Hash**, and **Copy Subject** — and for commits that haven't been pushed, **Drop Commit**.

Drop Commit removes that single commit from the branch's history cleanly. Grove checks that the commit isn't already on the remote before letting you use it — there's no force-push in Grove, so a commit that's already published can't be removed. Merge commits are also excluded — the action is disabled for them, with a tooltip explaining why. A dirty working tree blocks it too, with a clear message rather than a raw git error. If anything goes wrong mid-operation, Grove aborts and puts things back.

It confirms before doing anything. The confirmation dialog is the same style as the other destructive actions in Grove — worktree removal, push — so it shouldn't surprise you when it appears.

This rounds out the git log panel's usefulness for the common case where you committed something you didn't mean to, or committed too early, and want to undo it before the commit leaves your machine. Previously that meant opening a terminal and working through git commands yourself.

Grove 0.5.0 is up — [grove.molayab.com](https://grove.molayab.com) for a fresh download, or the in-app update check if you're already on 0.4.0.

The environment fix in 0.5.0 is the one I'd underestimated for longest. It showed up as a grab-bag of unrelated-looking failures — this agent can't find Python, that one won't push because SSH doesn't work — and each one looked like a misconfiguration or a bug in the tool itself. Fixing the underlying cause removed a whole category of those at once.
