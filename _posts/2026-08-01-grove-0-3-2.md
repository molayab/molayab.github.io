0.3.2 is a smaller release than 0.3.0 or 0.3.1 — no new spaces, nothing structural. It's a batch of the kind of fixes and small conveniences that pile up between the bigger releases, mostly things that came out of just using Grove day to day.

## Pick your own font

The Agent and Shell terminal panes, and the Diff view's rendered code, used to run on a fixed font with no way to change it. Settings now has a font family and size for the terminal panes, and a separate one for the diff view. The terminal font applies immediately to whatever's already open — you don't need to restart an in-progress agent session to see it — while the diff font picks up the next time you open a diff.

## The scroll wheel doesn't fight you anymore

Scrolling the Agent pane with the mouse or trackpad was quietly sending synthetic Up/Down arrow key presses to whatever CLI agent was running in it — a leftover from handling real full-screen terminal programs like `vim` or `less`, where arrow keys mean "move." None of the agents Grove runs are that kind of program, though, so an idle arrow key usually means something else to them: recalling prompt history, moving a menu selection. The result was that just scrolling up to read earlier output could quietly change what was in your input box. That's gone in 0.3.2 — scrolling scrolls, nothing else. The Shell pane is untouched, since a shell might genuinely be running `vim` or `htop`.

## Stale rows while scrolling during active output

If you scrolled back in the Agent or Shell pane while output was still coming in, you could end up looking at rows that hadn't actually updated — garbled or stale text until something forced a full redraw, which scrolling back to the bottom happened to do. That's fixed now: the terminal forces a redraw as new output arrives whenever you're not already at the bottom, so scrolled-back rows stay accurate instead of waiting for you to scroll away and back.

## Smaller things

- **The sidebar's Worktrees panel is now collapsible**, the same chevron-toggle the Git panel already had, for anyone who wants to reclaim the vertical space.
- **Grove remembers which worktree you were on** when you switch to a different workspace and back, instead of always resetting to the primary checkout.
- **Pinning a site in Home got a bit more flexible** — you can give it a custom title again instead of only the auto-derived one, and typing a bare host like `example.com` (no `https://`) no longer blocks saving.
