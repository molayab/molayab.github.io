0.5.1 is a patch, but it fixes the thing about the Home pane that had bothered me since I built it: pinned sites were global, so a site you pinned for one project showed up in every other project too. That's fixed, and the pane has a new name to go with the new behavior. Alongside that: a menu-bar shortcut for the git actions you'd otherwise dig into the sidebar for, and a fix for an Agent tab bug that could quietly kill a session you still needed.

## Browser, not Home

The pane that holds your pinned websites is now called **Browser**, with an icon that actually looks like one instead of a house. It was never really a home page — it's a place to keep the docs, dashboards, and tickets you want next to your code — so the name change is just catching up to what it's always done.

More importantly, pinned sites are no longer shared across every project you have open. Pin something while working on one project and it used to show up in every other project too, whether it belonged there or not. Now each project keeps its own set. If you do want a site to follow you everywhere — something like a docs site or a status dashboard you check regardless of what you're working on — you can promote it so it's shared across every checkout of that project, and demote it back down to just the one checkout if you change your mind.

## A Git menu, at the top

There's now a **Git** menu next to Edit and View in the menu bar, with Fetch, Pull, Push, and Save Changes… for whichever project is selected in the sidebar. It's the same four actions the sidebar's git panel already had — this just means you don't have to go find the sidebar to reach them, and they're one keystroke away from a menu you might already have open.

## The Agent tab stopped forgetting what's running

If you had an agent running in one project and then changed your default agent tool in Settings, coming back to that project's Agent tab could quietly restart the session — killing whatever the agent was doing — instead of leaving it alone. That's fixed. A live session now keeps running no matter what you change the default to elsewhere; a fresh tab picks up your new default the next time you actually start one.

## Smaller things

- **Zoom shortcuts in Browser.** Cmd+, Cmd-, and Cmd+0 now work on pinned sites, the same as they would in any other browser, for pages with text too small or too large to read comfortably.

## Get it

Grove 0.5.1 is up now — [grove.molayab.com](https://grove.molayab.com) for a fresh download, or the in-app update check if you're already on 0.5.0.

The global pinned-sites list is the kind of thing that's obvious in hindsight — every other space in Grove already followed the project you had open, and Home was the one exception nobody had gotten around to fixing. Worth doing before it became load-bearing for someone's workflow.
