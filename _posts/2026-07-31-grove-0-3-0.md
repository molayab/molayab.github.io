If you downloaded Grove before today, you've hit the "right-click → Open" dance on first launch. That's done as of this release — Grove is now signed with a real Developer ID and notarized by Apple, so a fresh download opens the way every other properly distributed Mac app does. I wrote about [what notarization actually means](/blog/2026/07/20/grove-notarization/) a couple weeks ago while the enrollment was still underway; this is the follow-through on that.

That's the headline of 0.3.0, but it's not the only thing worth calling out.

## Starting from nothing

Grove could previously only attach a folder that was already a git repository — there was no way to start a brand-new project from inside the app, so "I want to try Grove on a new idea" meant a detour to a terminal for `git init` before coming back. **New Project** in the sidebar now does that for you: pick a folder, and Grove initializes it as a repository and adds it as a workspace. Point Grove at an existing folder that isn't a repo yet, and it offers to fix that instead of just failing.

## Sync, not fetch/pull/push

The sidebar's git panel used to assume fluency in git's remote vocabulary — three separate buttons (fetch, pull, push), raw ahead/behind counters, "detached HEAD." That's a real barrier if git plumbing isn't something you think about day to day. The panel now leads with a single **Sync** button and a plain-English summary — "3 to send · 1 to get," or just "Up to date" — that fetches, pulls if you're behind, and reuses the existing confirmation if you're ahead and about to push. The three individual actions are still there, tucked behind an "Advanced" disclosure, for when you want the finer control.

## Chat and Notes (still Beta)

Two new spaces sit alongside Agent, Shell, and Files, both off by default — turn them on in Settings → Experimental if you want to try them:

- **Chat** is a lightweight Q&A pane that runs entirely on-device, via Apple Intelligence — no terminal, no tools, just a conversation. It's deliberately separate from the Agent tab: nothing runs in the background, and the conversation resets when you relaunch or move to a different worktree.
- **Notes** is a freeform notes pane scoped to whatever checkout you're on, the same way Home's pinned sites already work — so a worktree you spun up for a bugfix keeps its own notes, separate from the ones on your main branch.

Both are marked Beta because they're new and I want more real usage on them before calling them done — Chat in particular depends on what your Mac and macOS version actually support, so its usefulness will vary by machine.

## Smaller things that add up

- **Shell now supports multiple tabs**, the same pattern Home already uses for pinned sites — keep one shell running a dev server and another free for ad-hoc commands, instead of one bumping the other.
- **Settings got reorganized** from eight flat tabs into five grouped ones (General, Tools, Spaces, Experimental, License). The old layout had Git, Agents, and Shell as three separate tabs for what's really one concern — which external tool runs.
- **Grove now tells you when an update is available** — a dismissible badge in Settings and a "Check for Updates…" item in the Help menu, instead of no signal at all.
- **The sidebar notices branch changes made outside Grove.** Switch branches from a terminal, an IDE, or an agent CLI, and the git panel and worktree list catch up instead of showing a stale branch until your next in-app action.
- **Worktree removal is more forgiving** — one that fails to delete cleanly no longer gets stuck; there's a force-remove path for it now.
- **3-license activations are fixed.** If you bought the 3-license tier and couldn't activate it, that was a real bug on my end — a mistyped product ID meant Gumroad was rejecting every 3-license key. Sorry about that, and thanks to whoever reported it.

## Get it

Grove 0.3.0 is up now — [grove.molayab.com](https://grove.molayab.com) for a fresh download, or use the in-app update check if you're already on 0.2.0. Trial and licensing terms are unchanged.

Most of this release is about lowering the floor — starting a project without leaving the app, syncing without knowing git's verbs, opening the app without a workaround. None of it is flashy, but it's the stuff that decides whether someone who isn't already a git power user sticks around past the first ten minutes.
